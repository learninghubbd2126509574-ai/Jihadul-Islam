# Unity Earning - Android Application Project

This is the complete, buildable native Android application for **Unity Earning** developed with Kotlin and Jetpack Compose.

## Project Specifications
- **Package ID:** `com.unityearning.app`
- **Minimum SDK:** 24 (Android 7.0)
- **Target / Compile SDK:** 35 (Android 15)
- **Architecture:** Kotlin, Jetpack Compose, Material 3, Version Catalog (`libs.versions.toml`)

## Application Features Included
1. **Work / Submission History (কাজ):** Fixed exactly at 40 authentic submission records without lucky spin entries.
2. **User Points:** Strictly fixed at 3250 points across all screens and point exchange workflows.
3. **Lucky Spin Wheel:** Interactive spin wheel with fixed points integration.
4. **User Profile:** Full profile overview matching Habiba Akter (Gold Rank, ৳3,450 balance, ৳66,400 total income).

## How to Build the Real Debug / Release APK
1. Open this `android-project` folder in **Android Studio Ladybug (or newer)** or any machine with Java 17+ and the Android SDK installed.
2. Run the Gradle build command:
   ```bash
   ./gradlew assembleDebug
   ```
3. The genuine, installable APK will be generated at:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```
